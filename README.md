# แจ้งคาบสอน

เว็บแอปสำหรับครู ดูตารางสอนรายวัน/รายสัปดาห์ นับถอยหลังคาบที่กำลังสอน และเตือนก่อนเริ่มคาบ
ใช้ได้บนมือถือ เพิ่มลงหน้าจอหลักได้ และเปิดออฟไลน์ได้หลังเข้าครั้งแรก

- ไม่ต้องมีเซิร์ฟเวอร์ ไม่ต้องสมัครบัญชี ไฟล์ล้วน HTML/CSS/JS
- ข้อมูลของแต่ละคนเก็บในเบราว์เซอร์ของคนนั้นเอง ไม่ส่งไปที่ไหน คนที่รับลิงก์ไปจึงแก้ตารางของตัวเองได้โดยไม่กระทบคนอื่น

## วิธีเผยแพร่บน GitHub Pages

1. สร้าง repository ใหม่บน GitHub (ตั้งเป็น Public)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไว้ที่ราก (root) ของ repository:
   `index.html`, `sw.js`, `manifest.webmanifest`, `icon.svg`, `icon-192.png`, `icon-512.png`, `README.md`
3. ไปที่ **Settings → Pages**
4. ที่ **Build and deployment** เลือก **Deploy from a branch** แล้วเลือก Branch `main` โฟลเดอร์ `/ (root)` กด **Save**
5. รอประมาณ 1–2 นาที ลิงก์จะเป็น `https://ชื่อผู้ใช้.github.io/ชื่อ-repository/`
6. แชร์ลิงก์นี้ให้เพื่อนครูได้เลย

## ติดตั้งลงหน้าจอมือถือ

- **iPhone (Safari):** กดปุ่มแชร์ แล้วเลือก "เพิ่มไปยังหน้าจอโฮม"
- **Android (Chrome):** กดเมนู ⋮ แล้วเลือก "ติดตั้งแอป" หรือ "เพิ่มไปยังหน้าจอหลัก"

## ข้อควรรู้

- การเตือนและเสียงในแอปทำงานขณะเปิดแอปค้างไว้เท่านั้น ถ้าอยากให้เตือนแม้ปิดแอป ให้ใช้ปุ่ม **ตั้งค่า → ดาวน์โหลดไฟล์ปฏิทิน (.ics)** แล้วเปิดไฟล์เพื่อเพิ่มลง Apple Calendar หรือ Google Calendar
- ข้อมูลหายถ้าล้างข้อมูลเบราว์เซอร์ ให้สำรองไว้ที่ แท็บ **ตั้งค่า → สำรอง / กู้คืนข้อมูล**
- ปุ่มซิงก์ Google Calendar จะซ่อนอยู่ในเวอร์ชันนี้ (ต้องใช้คู่กับ Google Apps Script)

## ปรับตารางตั้งต้นให้คนอื่น

คนที่เปิดครั้งแรกจะเห็นตารางและชื่อตั้งต้นของเจ้าของแอป สามารถแก้เองได้ที่แท็บ **อัปเดต** (นำเข้า Excel หรือแก้คาบประจำ) และแตะชื่อด้านบนเพื่อเปลี่ยนชื่อ
ถ้าอยากเปลี่ยนค่าตั้งต้นของทุกคน ให้แก้ตัวแปร `SCHEDULE` และค่าเริ่มต้นของ `teacher` ใน `index.html`

## อัปเดตแอป

ถ้าแก้ไฟล์ใดๆ ให้เปลี่ยนเลขเวอร์ชัน `CACHE` ใน `sw.js` (เช่น `teach-alert-v2`) เพื่อให้เครื่องที่ติดตั้งไว้โหลดไฟล์ใหม่
